The native helper uses operating-system frameworks:
macOS: AppKit, Foundation, CoreGraphics and ImageIO.
Windows: Win32 User32/GDI, COM and Windows Imaging Component (WIC).
These frameworks are provided by the operating system, not copied into this
component. No third-party PNG decoder or GUI toolkit is bundled.

C++ standard-library/runtime code is supplied by the selected Xcode/MSVC
toolchain. The Windows build uses the Microsoft static C/C++ runtime.
